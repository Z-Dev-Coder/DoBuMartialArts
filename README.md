# DoBu Martial Arts & Fitness Academy

A fully responsive, multi-page website designed and built for a martial arts academy, featuring course listings, interactive class schedules, trainer profiles, and online member registration.

🔗 **Live Demo:** [https://z-dev-coder.github.io/DoBuMartialArts/](https://z-dev-coder.github.io/DoBuMartialArts/)

---

## Key Features

- **Multi-Page Layout**: Dedicated pages for Academy Home, Services & Classes, Instructor Profiles, About Us, and Student Registration.
- **Mobile-First Responsive Design**: Custom CSS3 media queries, Flexbox, and CSS Grid layouts optimized for mobile, tablet, and desktop screens.
- **Interactive UI**: Dynamic scroll animations, interactive timetable views, and client-side JavaScript form validation.
- **Live Deployment**: Hosted directly on GitHub Pages.

---

## Tech Stack

- **HTML5**: Semantic web markup and accessibility structure
- **CSS3**: Custom animations, transitions, Flexbox, and CSS Grid
- **JavaScript (ES6+)**: Scroll events, navigation toggles, dynamic DOM updates
- **Deployment**: GitHub Pages
